# 包装素材与面位匹配

将混合素材目录中的产品图、Logo、文字和条码，按证据对应到正确的SKU、销售套数、版本和包装盒面。防止凭文件名猜图、旧新Logo混用，以及改一处漏掉其他面位。

## 适合什么时候用

- 多SKU照片混在一个目录，需要先整理对应关系。
- 版面已有图位，但素材版本或用途尚不清楚。
- 系列套版前核查错图、错套数、错面位风险。

不生成图片、不抠图、不自动排版、不生成刀模，也不签发印刷或生产合格结论。

## 使用

在支持本地SKILL.md的工具中，将本目录放到该工具支持的技能目录，按该工具当前规则启用；也可直接阅读SKILL.md手工执行。不要覆盖同名旧版本，先比较或备份。若工具尚未发现技能，明确让其读取本目录的SKILL.md，不应宣称自动启用成功。

示例请求：

> 使用 $packaging-asset-mapper，只读检查我指定的素材目录，按已确认SKU清单和版面图位列出候选映射。不能确定的单列，原文件不动，不上传。

用户须提供允许读取的目录、当前SKU资料及面位需求。信息不足仍可整理候选，但不能猜测身份、结构或授权。图片查看工具不可用时如实写未做视觉核验。

## 输出

复用项目现有台账或references/mapping-record.md，给出逐槽位的“已确认 / 候选待确认 / 缺素材 / 不适用”状态及证据。映射确认不等于清晰度或印前通过。

## 文件

- SKILL.md：触发范围和工作流程。
- agents/openai.yaml：兼容工具可读取的界面元数据。
- references/mapping-record.md：空白登记与映射模板。
- references/source-decisions.md：来源、权利和边界。
- references/test-scenarios.md：8个合成测试情景。

无需第三方代码、模型、特定软件或外部skill。须有读取文件和查看图片的能力；没有该能力则仅能完成资料整理部分。
